This Week 4 project brings together the data analysis work completed across the previous three weeks into one clear and structured report. The project covers three datasets and demonstrates how data preparation, visualization, statistical analysis, and predictive modelling fit together in a complete analytical workflow.

The first part uses the World Bank fertility rate dataset. I focused on country-level values from 2000 to 2011, checked missing values, identified potential outliers using the interquartile range method, and used median imputation to prepare the annual values for comparison. I also created a normalized fertility measure and grouped countries into low, medium, and high fertility categories. The second part uses the economics dataset available through the R ggplot2 package. It includes monthly US economic observations from 1967 to 2015. I used line charts, a histogram, a scatter plot, and a decade comparison to explain unemployment and personal consumption expenditure trends. The third part uses the Kaggle Medical Cost Personal Dataset. It includes age, sex, BMI, number of children, smoking status, region, and medical insurance charges. I checked the data quality, prepared a cleaned dataset, explored charge patterns, tested the relationship between smoking status and charges, and examined the association between age and charges. A multiple linear regression model was also developed to predict insurance charges and evaluated using a separate test sample.

The project folder includes the original datasets, cleaned data files, R scripts, charts, statistical result tables, model diagnostic plots, a README file, and the final Word report. The analysis is written in a student-friendly style while keeping the methods and presentation professional. The report also explains the limitations of the datasets and models, including the fact that correlation does not prove causation and that predictive performance should be checked on unseen data. The master R script is provided so the complete workflow can be reproduced in RStudio. Before final submission, the script should be run locally and genuine execution screenshots should be added as evidence.
